# Criação de Dashboard através da IA

## Inteligência artificial escolhida: 
### Gemini

## Prompt Usado:
### Seja um Analista de Dados sênior e monte um dashboard interativo em formato HTML navegável, com os dados do documentos em formato JSON enviado. Por favor, atente-se os passos abaixo:

1- Analise os dados, e limpe-os, caso necessário;
2 - Atente-se a cor do dashboard para que alcance a todos, incluindo quem precisa de acessibilidade;
3 - Conte uma história, de acordo com as perguntas abaixo:
   - Quanto de vale cultura foi utilizado no (brasil, ou região, ou estado);
   - Média do valor gasto no (brasil, ou região, ou estado) no ano;
   - Grupo de descrição mais utilizado com o vale cultura.
   - 5 Estados com mais utilização do vale no ano;
   - 5 meses que foram mais utilizados no ano;
   - Total dos 3 meses mais utilizados, e com o que foram utilizados.

4 - Siga uma ordem: Dados mais abrangentes para os mais específicos. Em cima, pode ser o resultado de dados como cartão. Exemplo: Total de vale cultura usado no Brasil. 
5 - O dashboard tem que ser interativo. Ele pode ser filtrado por: Ano, região.

Os ajustes feitos foram para: 
- Retirar um gráfico sobre dados limpos;
- Diminuir o "Total dos 3 meses mais utilizados, e com o que foram utilizados" de 5 para 3 meses
